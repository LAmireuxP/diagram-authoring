# 各类型图表的结构与布局

流程图类（业务流程、程序流程、数据流程）先读 `symbols-gbt1526.md`。其余类型按下文约定。文中样式与箭头写法为 draw.io 语法，Mermaid 映射见 `format-mermaid.md`。

## 1. 流程图

- 规范：GB/T 1526-1989（符号见 `symbols-gbt1526.md`）
- 最小结构：端点符 → 输入 → 处理 → 判断 → 分支 → 端点符
- 布局：自上而下，主干居中，分支左右引出，判断出线标“是/否”
- 尺寸：处理 160×60，判断 160×80，起止 120×60；垂直间距 60，横向间距 80
- 主干坐标示例：起止 x=340，处理与判断 x=320；y 取 40、160、280、400…

## 2. 泳道图（跨职能流程图）

- 最小结构：每个角色一个泳道容器，节点放容器内，跨泳道连线用正交折线
- 泳道方向：横向（标题在左，流程自左向右）、纵向（标题在上，流程自上而下）；draw.io 中用 `horizontal=0` / `horizontal=1`
- 要求：
  - 节点 `parent` 指向泳道
  - 子元素用相对坐标，不得压标题栏：横向泳道 `x ≥ startSize`，纵向泳道 `y ≥ startSize`
  - 泳道按流程顺序排列
  - 泳道高度大于最底部子节点底边，留 ≥20px
- 横纵组合：外层横向总泳道，内嵌纵向子泳道

## 3. 系统架构图

- 最小结构：若干分层背景矩形 + 每层节点 + 层间连线
- 分层：客户端层 / 接入层 / 应用层 / 数据层 / 基础设施层
- 层背景：视觉矩形，不是容器（不用 swimlane，不加 `container=1`），`rounded=1;dashed=1;fillColor=#F5F5F5;strokeColor=#666666;verticalAlign=top;`，标层名
- 层内节点：绝对坐标，落在层背景范围内；同层同色同尺寸，水平排布，间距 ≥80
- 云图标：draw.io 用 `shape=mxgraph.aws4.<service>;`、`mxgraph.azure.*`、`mxgraph.gcp2.*`
- 连线：依赖用实线箭头，异步/消息用虚线；同列节点底出顶入，同行节点右出左入，保证连线笔直

## 4. ER 图

- 规范：Crow's Foot（推荐）或 Chen
- 最小结构：实体矩形（HTML 多行列字段）+ 关系连线 + 基数箭头
- 实体字段：主键加粗、外键斜体、左对齐
- 基数（draw.io 箭头）：一对一两端 `endArrow=ERone;`；一对多一个 `ERone` 一个 `ERmany`；零或多 `ERzeroToMany;`；零或一 `ERzeroToOne;`
- 聚合、组合：`endArrow=diamond;endFill=0;`（聚合）、`endFill=1;`（组合）

## 5. 网络拓扑图

- 最小结构：核心层居中，汇聚、接入层辐射
- 图标：draw.io 用 `shape=mxgraph.cisco19.<device>;`
- 布局：核心居中，或按机房、楼层分区块
- 连线：实线为物理链路，虚线为无线或逻辑链路；带宽标在标签里

## 6. UML 类图

- 最小结构：三段式类框（类名、属性、方法）+ 关系箭头
- 类框：HTML `<p>` 加 `<hr>`，写法见 `format-drawio.md` §6；样式 `verticalAlign=top;align=left;overflow=fill;`
- 关系箭头：继承 `block;endFill=0;`、实现 `block;endFill=0;dashed=1;`、组合 `diamond;endFill=1;`、聚合 `diamond;endFill=0;`、依赖 `open;dashed=1;`、关联 `open;` 加多重性标签

## 7. UML 时序图

- 最小结构：顶部参与者矩形 + 生命线 + 水平消息箭头
- 消息：实心箭头为同步调用，开口箭头为返回，虚线为响应
- 激活条：生命线上的细矩形
- 自调用：正交折线回环

## 8. 状态图

- 最小结构：起始状态 + 若干状态 + 结束状态
- 转换：带事件标签的箭头
- 嵌套状态：外层容器

## 9. 思维导图

- 最小结构：中心主题居中，一级分支辐射，逐级变细
- 连线：曲线（`curved=1;`）
- 层级：一级分支最粗（`strokeWidth=3;`），逐级递减；同一父节点的分支同色

## 10. 组织架构图

- 最小结构：树形，根在上，同级同 y
- 节点：姓名与职位两行；高层用 `shape=card;`
- 连线：父底出、子顶入，无箭头（`endArrow=none;`）
- 虚线表示矩阵式、虚线汇报（`dashed=1;`）

## 11. 通用布局

1. 对齐 10px 网格；同类节点尺寸一致
2. 间距：垂直 ≥60，水平 ≥80；泳道内可缩到 40/60
3. 同层节点中心对齐
4. 避免交叉；必要时重排或断线
5. 整图四周留 ≥40px
6. 同类节点同色；语义色固定：起止绿、判断黄、错误红
7. 连线走直：同列底出顶入，同行右出左入
